## 一、我们收集哪些信息

### 1.1 您主动提供的信息

- **登录信息**：当您通过应用内百度网页登录流程登录账号时，应用会接收并保存百度贴吧返回的登录态 Cookie（包含 BDUSS、STOKEN 等字段），用于在后续请求中标识您的登录身份。
- **账号公开信息**：应用会通过接口读取并向您展示您在百度贴吧的公开账号信息（如用户名、头像 URL、UID、吧内等级）。
- **您发布的内容**：当您使用"发帖"功能时，您输入的标题、正文、图片、表情等内容会通过百度贴吧官方接口提交至百度服务器。
- **搜索关键词**：当您使用全站搜索（搜吧 / 搜贴 / 搜人）时，搜索词会作为请求参数发送至百度贴吧接口，**应用不在本地保存搜索词**。

### 1.2 使用过程中自动产生的信息

- **网络请求公共参数**：按百度贴吧移动端公共协议自动在请求中携带 User-Agent、Referer、客户端版本号等，用于接口正常返回数据。
- **本地缓存**：为提升再次访问速度，应用会在设备本地保存最近浏览过的帖子列表、帖子详情、图片资源、头像等（采用 LRU 策略，占用空间超阈值时按"最近最久未使用"顺序自动清理）。
- **阅读历史**：当您打开帖子或吧主页时，应用会在本地记录浏览记录（仅保存于您的设备），用于"我的 → 浏览历史"功能。

### 1.3 设备权限

应用仅申请以下三项系统权限，且全部用于实现核心功能：

| 权限名称 | 用途 | 申请时机 |
| --- | --- | --- |
| `ohos.permission.INTERNET`（网络访问） | 访问百度贴吧接口、加载图片与头像 | 安装时声明 |
| `ohos.permission.VIBRATE`（震动反馈） | 点赞、签到成功、收藏成功等操作的触觉提示 | 使用对应功能时 |
| `ohos.permission.KEEP_BACKGROUND_RUNNING`（后台运行） | 保证"数据转移"型任务在后台继续完成（如发帖上传、收藏同步等异步流程） | 安装时声明 |

除上述权限外，本应用**不申请**通讯录、位置、相册、相机、麦克风、短信、电话、存储等任何其他系统权限。

**特别说明**：保存图片到相册通过 HarmonyOS `SaveButton` 安全控件实现，**不申请 `WRITE_IMAGEVIDEO` 永久写相册权限**，您每次点击"保存"时会单独触发系统授权。

## 二、我们如何使用您的信息

我们仅在以下范围内使用您的个人信息：

- 展示贴吧内容、维持登录态、保存本地数据；
- 执行您主动发起的操作（点赞、收藏、签到、发帖、搜索等）；
- 异常登录或异常请求时的必要提示与拦截。

我们**不会**：

- 将您的个人信息用于本声明未载明的其他目的；
- 基于您的个人信息进行用户画像、自动化决策或个性化广告推送；
- 集成任何第三方广告 SDK、统计分析服务、崩溃上报服务或推送服务。

## 三、信息的存储与保护

### 3.1 存储位置

本应用所有用户数据均存储在您的设备本地（HarmonyOS 应用沙箱），**不主动上传到任何由我们控制的服务器**。

### 3.2 存储期限

- 登录态 Cookie 在您主动退出登录或卸载应用时被清除；
- 收藏、签到、屏蔽列表、字号偏好、沉浸光感偏好等本地化数据将持续保留，直至您主动删除、应用卸载或恢复出厂设置；
- 缓存（帖子列表、图片、头像）采用 LRU 策略自动清理。

### 3.3 安全措施

- 登录 Cookie 加密保存在应用沙箱内，沙箱外应用无法访问；
- 网络请求统一使用 HTTPS 协议；
- 应用未运行时，不会在后台进行任何数据收集或网络请求（`KEEP_BACKGROUND_RUNNING` 仅在您主动发起的"数据转移"型任务进行中保留任务完成）。

请注意：尽管我们采取了上述合理的安全措施，但任何互联网传输或存储都无法保证 100% 安全。请妥善保管您的设备，避免在已 Root / 已越狱的设备上使用本应用。

## 四、信息的共享与披露

### 4.1 我们不会主动共享

除本声明明确列出的情况外，我们**不会**向第三方共享、转让或出售您的任何个人信息。

### 4.2 必要的接口调用

当您主动使用本应用的功能时，您的部分必要信息会通过百度贴吧官方接口与百度服务器进行交互，相关数据处理行为请参阅百度公司公布的隐私政策（<https://ai.baidu.com/ai-doc/PRIVACY/WkQb6lW4d>，或百度当前有效的隐私政策链接）。

### 4.3 法律要求

在以下情况下，我们可能会依法披露您的个人信息：遵守适用的法律法规、法院判决或其他法律程序；配合有权机关的合法调查；在紧急情况下为保护您或他人的生命安全、财产利益所必需。

## 五、您的权利

- **访问与查看**：可在应用内查看登录账号、收藏列表、签到记录、浏览历史、屏蔽列表等。
- **删除与清除**：
  - 清除浏览历史 → 我的 → 浏览历史 → 管理；
  - 删除收藏 → 收藏 Tab → 编辑模式；
  - 退出登录 → 我的 → 设置 → 退出登录（清除登录态 Cookie）；
  - 卸载应用 → 清除全部本地数据。
- **撤回授权**：HarmonyOS 系统"设置 → 应用 → TiebaPura → 权限"中可关闭对应权限；关闭后对应功能不可用，但不影响其他功能。
- **投诉与反馈**：通过下方"联系我们"渠道联系，我们将在 15 个工作日内作出答复。
