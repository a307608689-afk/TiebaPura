# 一镜到底动画实现

> 帖子详情页图片宫格 ↔ 全屏图片预览的「一镜到底」打开/退出动画。
> 演进经历 4 代方案、真机多轮翻车，最终形态为**自绘飞行层 + 页内同树预览层**。
> 本文沉淀全部机制结论与踩坑，后续任何转场类需求先读本文再动手。
>
> 状态：2026-09-27 定稿，构建通过，真机回归待用户。

---

## 1. 最终形态（先看结论）

```
点击宫格图
  ↓ componentUtils 取格子实时矩形（px→vp）
  ↓ 本地缓存文件解码一次 → PixelMap（宽高比 + 交接位图一并取得）
飞行层：单一图片节点（objectFit Cover）装在弹簧插值的矩形容器里
        格子矩形 ──springMotion(0.34, 0.9)──→ Contain 矩形（黑幕同步淡入、顶栏联动淡出）
  ↓ 弹簧 onFinish（真实落定帧）
预览层挂载（页内同树，非模态），首帧直接上屏同一张 PixelMap（零解码空窗）
  ↓ 预览首图 onComplete（或 250ms 兜底）→ 撤飞行层

退出（关闭钮/返回键/侧滑）
  ↓ 飞行层先呈现预览当前帧（同一 PixelMap，零空窗）→ 同帧卸载预览
飞行层 springMotion(0.42, 0.9) ≈400ms 飞回格子矩形（滚动跟随：贴住格子一起走）
  ↓ onFinish 撤层
```

**为什么这套结构「不可能闪」**：全程只有一张已解码的图、一个矩形在动；预览挂载在飞行层之下、
飞行层等预览首图真实上屏（`onComplete`）才撤——预览首帧无论怎么抖都被飞行层稳定末帧盖住。

## 2. 方案演进史（每一代为什么死掉）

### v1：系统 `sharedTransition`（Exchange）跨路由页 ❌

router 前后两页组件挂同 id，系统 Exchange 转场。

- **比例跳动（机制固有）**：Exchange 把起点**快照拉伸**到终点矩形。宫格是 Cover 裁切（3:4）、
  全屏是 Contain（9:16），两端框比例不同 → 中间帧必然形变。**参数无法修**。
- **概率性飞错格子**：跨页 id 配对依赖全局索引编号，宫格首图对不上全局列表时 offset 回退 0 →
  重复 id → 系统配错起点。
- 结论：**Exchange 适合两端同比例的场景；Cover→Contain 一律不要用。**

### v2：官方 `geometryTransition` + `bindContentCover` ❌

官方《共享元素转场 (一镜到底)》的标准姿势，图库观感理论上完美（转场中系统在 Overlay 层
以**两端各自渲染形态 + 透明度交叉**呈现，Cover/Contain 都保比例 → 无拉伸）。

实测三连败：

| 症状 | 根因 |
|---|---|
| 退出直接消失、无动画 | `GeometryTransitionOptions.follow` 默认 false——**恒在组件树中的固定端（宫格）不参与转场**，关闭方向配对失败。d.ts 原文："apply the animation to components that are always in the component tree"。两端都 `{ follow: true }` 才对 |
| 打开途中两个比例的图重叠（双影） | **两端内容交叉淡化是机制本身**：替身同时渲染两端内容切透明度，Cover 块与 Contain 全屏必然同时可见 |
| 退出闪现 | 同上：交叉淡化让大图在飞行前半段就淡光了 |

结论：**geometryTransition 只适合两端内容视觉一致的场景（同图同 fit）；Cover→Contain
的「裁切放松」型 morph 的交叉淡化不可避免 → 自绘。**

### v3：自绘飞行层（最终形态）✅

核心洞察：**Cover 装在「格子矩形 → Contain 矩形」插值的容器里 = 全程保比例的单图 morph**：

- t=0：容器=格子矩形，Cover 渲染 ≡ 宫格格子（逐像素）；
- t=1：容器=Contain 矩形，Cover 填满 ≡ 预览页 Contain 显示（逐像素）；
- 中间帧：Cover 任何帧都保比例裁切 → **单节点、单内容、零交叉淡化**。

#### v3.1 的坑：仍用 bindContentCover 承载预览

- **模态宿主底色默认白色**（BindOptions.backgroundColor 默认 `Color.White`）→ 内容树比模态层
  慢一帧时白底顶穿黑幕 = 全屏白闪。需显式 `backgroundColor: Color.Black`。
- **模态层是独立合成层，挂载首帧永远可能落后一拍**——时序怎么调都有竞态 → **弃用模态，
  预览改为页内同树挂载**（层级与时序完全受控）。

## 3. 最终架构与代码分布

### 3.1 `pages/ImagePreview.ets`

- **`PreviewView`（export @Component）**：预览主体，原 @Entry 页面逻辑全量内化
  （流式补页 / 高清链 / 保存 / 缩放手势）。两种宿主：
  - 路由页薄壳 `@Entry ImagePreview`（`pages/ImagePreview` 注册保留，楼中楼详情
    SubPostDetail 仍 pushUrl，系统默认转场零变化）；
  - ThreadDetail 页内全屏层（一镜到底路径）。
- 关键属性：
  - `previewParams`：路由/宿主透传参数（urls/index/流式补页上下文）；
  - `closing`（@Prop @Watch）：宿主请求关闭 → 复位缩放 → `onClose(currentIndex)`；
  - `initialPixelMap` / `initialPixelMapPath`：交接位图及其来源路径——初始图首帧直接上屏
    位图，**仅当该图落地了「不同路径」的更高清文件（720 升级）才切回 URL 源**，
    同文件路径变化不切（防自 swap 二次解码闪）；
  - `onReady`：初始图 `onComplete` 回调，宿主据此撤飞行层。
- ⚠️ 本 SDK（API26）Image **没有 `onLoad`，是 `onComplete`**。

### 3.2 `pages/ThreadDetail.ets`

状态：`previewShow`（预览层）/ `previewClosing` / `previewParams` /
飞行层一组（`morphOverlayShow/BgOpacity/X/Y/W/H/Radius/Src/PixelMap/FollowY`）/ `morphEpoch`（代次防过期回调）/ `openingMorph`（打断标记）/ `openCellNodeId/openStartRect` / `morphStartScrollY`。

方法：

| 方法 | 职责 |
|---|---|
| `gridCellNodeId()` | 宫格定位 id：`dtgu_${URL哈希}`（v2.4：按**点击图自身 URL** 生成；楼中楼单张同样参与。早期用「首图 URL 推全局偏移」，首图不在全局列表/重复时整组映射错位——飞行起点飞到别的格子、预览 index 指向全局第 0 张，已废弃） |
| `getVpRectById()` | **componentUtils 返回 px**，统一 px2vp；异常/零尺寸返回 null |
| `getMorphLocalPath()` | 飞行图源：优先高清档 pv_ → 基础档（与宫格/预览同缓存文件，交接帧逐像素一致） |
| `decodeMorphPixelMap()` | 本地文件解码 PixelMap（宽高比从位图读，一次解码全链复用） |
| `containRectFor()` | 按宽高比算全屏 Contain 矩形 [x,y,w,h] |
| `openImagePreview()` | 解码 → 飞行层起飞 → **onFinish 挂预览**（不用标称时长估算）→ onComplete/250ms 撤层 |
| `finishClosePreview(index)` | 飞行层呈现预览当前帧（同 PixelMap）→ 同帧卸预览 → 弹簧飞回格子（滚动跟随启用） |
| `interruptOpenMorph()` | 打开 morph 打断：弹簧从当前位置反向接续飞回格子 |
| `onBackPress()` | 页级返回拦截：预览开=关闭；打开中=打断；其它残留=作废撤层 |

预览层与飞行层都是 DetailRoot 根 Stack 的子节点：**预览在前、飞行层在后（飞行层在最上）**。

## 4. 关键机制与踩坑清单（按代价排序）

### 4.1 时序类

1. **交接时机必须用弹簧 `onFinish`**，不能用标称 duration 估算——`springMotion` 的 duration
   仅标称值，弹簧自计时；差几十毫秒就是「闪一下」。
2. **撤飞行层的时机 = 预览首图 `onComplete`**（+250ms 兜底防卡死）——预览没画好之前
   屏幕上始终是飞行层末帧。
3. **morph 代次（epoch）防过期回调**：异步解码/定时器回调一律校验 epoch，连点/打断/重复
   开关互相作废。

### 4.2 闪烁类（每一帧都要过一遍「这一帧和上一帧是否逐像素一致」）

4. 新 Image 节点对同一本地文件**仍会重新解码**（1~2 帧空窗）→ 全链路传 PixelMap，零二次解码。
5. 高清升级落地切源时，**路径相同不切**（`initialPixelMapPath` 比对），否则自己 swap 自己闪。
6. bindContentCover 宿主底色默认白（若未来恢复模态方案，必须 `backgroundColor: Color.Black`）。

### 4.3 命中测试类

7. **`HitTestMode.None` 只豁免自身，子节点默认仍参与命中**——纯视觉浮层必须给每个子节点
   逐个设置，否则动画期间挡住底下点击（「退出后要等一会才能点下一张」的根因）。
8. 顶栏 opacity 0 仍参与命中，需配 `.enabled(false)`。

### 4.4 图层级

9. **官方标题栏（Navigation title）绘制在页面内容层之上**，页内浮层盖不住它 → 顶栏透明度
   与飞行层黑幕浓度反向联动：`opacity = immersiveHidden ? 0 : 1 - morphBgOpacity`，
   打开时顶栏随黑幕淡出、关闭时随黑幕淡入，全程无跳变。
10. bindContentCover/模态层是独立合成层——凡是「内容树挂载 + 独立层首帧」的组合都有竞态，
    能同树就不要跨层。

### 4.5 动画类

11. **springMotion 可中断可重定向**：再次 `animateTo` 同一属性，弹簧从当前实时位置接续飞向
    新目标——打开中按返回反向飞回就是白送的，前提是状态机清晰（`openingMorph` + epoch）。
12. 打断/关闭的目标格子要**重查实时矩形**（`getVpRectById`）——打断期间页面可滚动。
13. **滚动跟随**：关闭/打断 morph 期间，把「当前滚动 − morph 起点滚动」的差值反向补偿到
    飞行容器的 `translate`（与弹簧驱动的 position 分属不同属性，互不干扰），飞行图贴住格子。
    打开方向目标是屏幕固定位置，不跟随。挂点复用 `onDetailScroll`（竖屏/分栏右栏共用 scroller）。

### 4.6 其它 SDK 事实（本机 API26 实测）

14. `componentUtils.getRectangleById` 返回 **px**（size/windowOffset 均 px），须 px2vp。
15. Image 无 `onLoad`，加载完成回调是 `onComplete`。
16. @Entry 的 build 根必须是容器组件（薄壳要包一层 Stack）。
17. `geometryTransition(id)` 空串 = 解除绑定（SDK 语义）。
18. 导出组件 + @Entry 薄壳可以共存于一个页面文件；路由页参数经 props 下传。

## 6. 真机回归清单

1. 打开：格子→全屏全程单图、比例正确、无重叠双影、落定无闪烁
2. 退出（关闭钮/返回键/侧滑三路径）：≈400ms 飞回格子，交接无黑帧/白帧
3. 预览内滑动换图后退出：飞回对应格子；滚动页面后打断反向：飞回格子新位置
4. 退出动画进行中立即点另一张图：新打开动画无缝接管
5. 打开中按返回：弹簧反向打断，详情页保持
6. 顶栏随黑幕联动淡出/淡入；沉浸阅读显隐回归
7. 高清升级（720）静默替换正常；保存图库正常；楼中楼单张/补页图退化为淡入淡出（预期）
8. 滚动跟随：退出动画中快速下滑，飞行图贴住格子一起走
